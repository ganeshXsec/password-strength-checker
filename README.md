# Password Strength Checker

## Overview
A beginner-friendly cybersecurity project built with Python
to evaluate basic password-strength indicators and provide
recommendations for improving password security.

## Features
- Password length checks
- Uppercase and lowercase character checks
- Number and special character checks
- Detection of selected common passwords
- Basic repeated-character and sequence checks
- Password improvement suggestions
- Hidden password input using Python getpass

## Technologies
- Python 3
- Regular expressions (re)
- getpass module

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:

   python password_checker.py

On Kali Linux, use:

   python3 password_checker.py

## Security and Privacy
The script evaluates input locally and does not intentionally
save or transmit passwords. Use only test passwords, never
your real account passwords.

## Limitations
This project uses simple rules and a small common-password
list. It is not a complete password audit or security guarantee.
